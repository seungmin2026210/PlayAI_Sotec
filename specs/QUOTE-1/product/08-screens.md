# 08. 화면 구성

## 8.0 전체 셸 (사이드바 · 대시보드)

로그인 후 진입점은 좌측 사이드바 + 상단바를 가진 셸(`frontend/src/design/AppShell.tsx`)이며,
첫 화면은 대시보드(`/dashboard`)다. 디자인은 Claude Design 프로젝트("로그인 및 대시보드
시스템 구축")의 `Dashboard.dc.html` 을 그대로 이식했다.

- 사이드바 메뉴: **대시보드** / **계약관리**(그룹) → **견적관리**(`/quotes`, 기존 1단계
  화면 그대로) · **구매관리**(`/purchase`) · **계약관리**(`/contract`).
- 견적관리를 제외한 구매관리·계약관리, 그리고 대시보드의 통계·갱신 캘린더·예산 집행
  카드는 전부 **범위 밖(향후 단계)** — 백엔드 연동 없이 디자인 목업 데이터/"준비 중"
  placeholder(`pages/Placeholder.tsx`) 만 표시한다. 1단계 실제 데이터는 견적관리 하나뿐이다.

## 8.1 목록 화면 (`/quotes`)

- 견적서 List 조회 (페이지네이션).
- 그룹관리자는 **본인 그룹 데이터만** 조회 (서버에서 강제 필터).
- 컬럼(제안): 관리번호 · 그룹 · 견적서명 · 수신처 · 발행일자 · 공급가액 합계 · 상태 · 잠금 여부 · 등록시간.
- 목록 엑셀 export 버튼.
- **❓ 미정 (open-7)**: 최종 검색/필터 항목.
  → **임시 결정** (잠정 제안 채택): 관리번호, 견적서명(부분일치), 그룹, 상태, 발행일자 범위(from~to), 담당자명. 필터 정의는 `backend: routers/quotes.py: list_quotes()` 쿼리 파라미터 1곳 + `frontend/src/pages/QuoteList.tsx` 필터바 1곳.

## 8.2 등록 / 상세 화면

- **등록** (`/quotes/new`, 전체관리자만): [05-data-fields.md](./05-data-fields.md) 입력 폼. 항목 행 추가/삭제, 부가세 포함/미포함 1회 선택, 실시간 합계·절사·부가세 미리보기.
- **상세** (`/quotes/:id`): 전체 필드 표시. 자사 정보 자동 표시.
  - 버튼 배치: **오른쪽 위(page-head)** = 문서 계열 `엑셀` `PDF` `개인메일 발송` `수정` + `목록으로`.
    **오른쪽 아래(견적 항목 카드 밑)** = 상태변경 계열 `승인` `반려` `취소` `구매관리 반영(잠금)` `삭제`.
  - 전체관리자: 위 전체. 그룹관리자: `엑셀` `PDF` `목록으로` 만(나머지 `SuperAdminOnly` 로 숨김).
  - 각 버튼은 **해당 액션이 불가능하면 비활성이 아니라 화면에서 숨김**(disabled 아님):
    `엑셀`/`PDF`/`개인메일 발송`은 상태가 `승인됨`일 때만 노출(제출됨/반려됨/취소됨이면 숨김 — 승인 전·반려·취소된 견적서는 정식 문서로 내보내거나 발송할 대상이 아님),
    `수정`/`삭제`는 읽기전용(`read_only=true`: 승인됨/반려됨/취소됨/구매관리 반영됨)이면 숨김,
    `승인`/`반려`/`취소`는 상태가 `제출됨`이 아니면(또는 잠금 상태면) 숨김,
    `구매관리 반영(잠금)`은 상태가 `승인됨`일 때만 노출(그 외 상태에서는 숨김).
  - 승인됨 전이 즉시 읽기전용 — `승인` 이후에는 `반려`/`취소`/`삭제`/상단 `수정` 버튼이 전부 사라지고
    `엑셀`/`PDF`/`개인메일 발송`/`구매관리 반영(잠금)` 만 남는다.
  - 계산부는 별도 표가 아니라 **견적 항목 표 `tfoot`** 에 통합: 공급가액 합계(십만단위 절사) / 세액(10%) / 합계금액 + 항목 합계·절사 기준 각주. 용어는 export 양식과 일치([`tech/09-export.md`](../tech/09-export.md)).
- **수정** (`/quotes/:id/edit`, 전체관리자만): 등록 폼 재사용, 기존 값 프리필.

## 8.3 관리 기능

- Export: 개별 엑셀/PDF, List 엑셀 ([`tech/09-export.md`](../tech/09-export.md)).
- 발송: 개인메일 버튼 → "이메일 발송 기능은 준비 중입니다" 토스트 ([04-scenarios.md](./04-scenarios.md) 4.6).

## 8.4 개발 우선순위

**❓ 미정 (open-8)** — 잠정 제안 순서 채택:

1. 목록/상세 조회
2. 신규 등록 (채번 포함)
3. 상태 전이 (승인/반려/취소/삭제)
4. Export
5. 발송(자리표시)

이번 구현은 1~5 전부 포함.
