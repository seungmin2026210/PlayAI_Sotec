# 02. 프로젝트 범위

## 2.1 포함 범위 (1단계)

- 견적서 등록 / 수정 / 취소 / 삭제
- 승인 / 반려 처리
- 견적서 발송 버튼(자리표시, 실제 발송 로직 제외)
- 견적서 export (개별 엑셀/PDF, 목록 엑셀)
- 역할 기반 조회 권한 분리 (전체관리자 / 그룹관리자)
- 관리번호 자동 채번

## 2.2 범위 외 (향후 단계)

- 예산 관리 기능
- 갱신 캘린더 기능
- 자산 배정 이력 자동 기록 기능
- 실제 로그인 인증 (출퇴근 프로그램 API 연동 예정)
- 이메일 실제 발송 로직 (SMTP 등 연동)
- 구매관리 시스템과의 실제 데이터 연동 로직
- 견적서 수정이력(감사로그) 기능 — **❓ 미정** ([04-scenarios.md](./04-scenarios.md) 4.7 참고)
- 그룹관리자 등록/수정 권한 확장 — **❓ 미정** ([03-users-and-roles.md](./03-users-and-roles.md) 3.1 참고)

## 2.3 이번 구현에서의 처리 방침

- 범위 외 항목 중 **자리표시가 필요한 것**(발송 버튼, 구매관리 연동 잠금)은 UI/훅만 구현하고 실제 로직은 비운다.
- **❓ 미정** 항목은 [`tech/10-provisional-decisions.md`](../tech/10-provisional-decisions.md)의 임시 결정에 따라 구현하되, 상수/정책 함수 1곳에 격리하여 협의 후 교체가 쉽도록 한다.
