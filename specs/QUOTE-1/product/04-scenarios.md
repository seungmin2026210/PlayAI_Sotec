# 04. 핵심 시나리오

## 4.1 신규 등록 (전체관리자 전용)

1. 전체관리자가 입력: 견적서명 · 발행일자 · 담당자명 · 그룹 · 수신처(고객사) 정보 · 항목/갯수/금액.
2. 부가세 포함/미포함을 **견적서 단위로 1회** 선택.
3. 저장 시:
   - 관리번호 자동 채번 ([06-management-number.md](./06-management-number.md)).
   - 자사 회사정보(사업자등록번호·대표자명) 자동 반영 (상수, 수정 불가).
   - 상태값 `제출됨`으로 자동 전환 (별도 "초안" 임시저장 단계 없음).

## 4.2 취소 / 수정

- **수정**: 상태값이 `제출됨`인 동안, 구매관리 데이터가 반영되기 전까지, **전체관리자만** 등록된 견적서 내용 수정 가능 (1단계 포함 범위로 확정). **승인됨으로 전환되면 이후 수정 불가**(읽기전용 보존, 4.4 참고).
  - **❓ 미정 (open-10)**: 수정 가능 필드 범위, 수정 시 상태값 처리, 수정 이력 기록 여부.
  - → **임시 결정**: (a) 전체 필드 수정 가능, (b) 수정해도 상태값 유지(되돌리지 않음), (c) `updated_at` 갱신만, 별도 감사로그는 미구현. 정책 함수 `services/status.py: apply_edit_policy()` 1곳에 격리.
- **취소**: 상태값이 `제출됨`인 동안, 구매관리 데이터 반영 전까지, **전체관리자만** 가능. **승인됨은 취소 불가**(반려/취소는 승인 전에만 선택).
  - 취소 시 상태값을 `취소됨`으로 전환 (데이터 삭제 안 함, 이력처럼 보존).
- 그룹관리자는 조회만 가능 → 취소/수정 권한 없음.

## 4.3 삭제

- 상태값이 `제출됨`인 동안, 구매관리 데이터 반영 전까지, **전체관리자만** 삭제 가능. **승인됨은 삭제 불가**.
- 삭제 시 해당 관리번호는 **결번 처리(재사용 금지)** — [06-management-number.md](./06-management-number.md).
- 구현: 물리 삭제 대신 `deleted_at` soft delete + `retired_numbers` 기록. 목록·상세에서 제외.

## 4.4 승인 / 반려

- 전체관리자가 상세화면에서 `승인` 또는 `반려` 버튼 선택.
- **승인**: 상태값 `승인됨`으로 전환. **승인된 견적서는 이후 수정/취소/삭제 모두 불가 — 즉시 읽기전용 보존**(반려됨과 동일하게 취급, 되돌릴 방법 없음).
- **반려**:
  - 반려 사유 입력 **(필수)** — 미입력 시 반려 처리 불가.
  - 원본 견적서는 상태값 `반려됨`으로 **읽기전용 보존** (관리번호 결번 아님).
  - 재제출은 원본 수정이 아니라 **새 관리번호로 신규 등록**.
  - 원본↔재제출 연결 "이전 관리번호 참조" 필드는 **이번 스코프 보류**.

## 4.5 구매관리 연동 (자리표시)

- 구매관리 시스템에서 데이터가 올라오면 해당 견적서는 상태값과 무관하게 **읽기전용(잠금)** 으로 전환 → 이후 취소/수정/삭제 불가.
- 이번 단계: 실제 연동 로직 없이 **잠금 플래그(`purchase_locked`) + 토글 훅(자리표시)** 만 구현.
- **❓ 미정 (open-4)**: 반영 트리거 방식(수동 체크/자동 연동/파일 업로드) 미정.
  - → **임시 결정**: 전체관리자용 "구매관리 반영(잠금)" 수동 토글 버튼 제공. 실제 연동 설계 시 교체.

## 4.6 발송 (개인메일)

- 발송 버튼은 노출하되, 클릭 시 **"이메일 발송 기능은 준비 중입니다"** 안내만 표시.
- 실제 SMTP 연동 등 발송 로직 없음.

## 4.7 견적서 변경이력 (감사로그)

**❓ 미정 (open-5)**: 개별 견적서의 등록/수정/상태변경 이력을 별도 기록·조회하는 감사로그 기능의 이번 스코프 포함 여부 미정.

- 4.4의 "반려 시 원본 보존" 규칙이 최소한의 이력 추적을 일부 대신함.
- → **임시 결정**: 감사로그 UI/조회 기능은 **미구현**. 단, 데이터 레벨에서 `created_at` / `updated_at` / `status` 전이 시각(`approved_at` 등)은 남긴다. 향후 감사로그 도입 대비.

## 4.8 Export

- **개별 견적서**: 엑셀 / PDF 추출.
- **견적서 List**: 엑셀 추출만 지원 (PDF 미지원은 의도된 설계).
