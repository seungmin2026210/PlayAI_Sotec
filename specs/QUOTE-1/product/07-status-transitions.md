# 07. 상태값 및 전이 규칙

## 7.1 상태값 (확정)

`제출됨` → `승인됨` / `반려됨` / `취소됨`

- 별도 "초안" 상태 없음: 등록 완료 즉시 `제출됨`.
- "구매관리 데이터 반영"은 상태값이 아니라 **별도의 잠금 플래그(`purchase_locked`)** 로 취급 — 상태값과 무관하게 반영되는 순간부터 읽기전용.

내부 코드값:

| 표시 | 코드 |
|---|---|
| 제출됨 | `SUBMITTED` |
| 승인됨 | `APPROVED` |
| 반려됨 | `REJECTED` |
| 취소됨 | `CANCELLED` |

## 7.2 전이 조건 (확정)

| 전이 | 조건 / 액션 | 수행 권한 |
|---|---|---|
| 제출됨 → 승인됨 | "승인" 버튼 클릭 | 전체관리자 |
| 제출됨 → 반려됨 | "반려" 버튼 클릭 + 사유 입력(필수) | 전체관리자 |
| 제출됨 → 취소됨 | 취소 처리 (승인 전까지만) | 전체관리자 |
| (모든 상태) → 읽기전용 잠금 | 구매관리 데이터 반영 (자리표시 토글) | 시스템(연동, 상세 미정) |
| 반려됨 → (신규 제출됨) | 재제출 = 새 관리번호로 신규 등록 (원본은 반려됨 유지) | 전체관리자 |

허용되지 않는 전이(예: `승인됨 → 반려됨`, `승인됨 → 취소됨`, `취소됨 → *`, `반려됨 → 승인됨`) 시도 시 `409 Conflict`.

## 7.3 수정 / 삭제 규칙 (확정)

- **수정**: 승인 전(`제출됨`)까지, 전체관리자만. 상태값은 유지(임시 결정, [04-scenarios.md](./04-scenarios.md) 4.2).
- **취소**: 승인 전(`제출됨`)까지, 전체관리자만. 상태값 `취소됨`.
- **승인됨** 이후: 수정/취소/삭제 모두 불가 → 읽기전용 표시(구매관리 반영 여부와 무관하게 승인 즉시 읽기전용).
- 구매관리 반영 이후: (승인됨과 별개로) 수정/취소/삭제 모두 불가 → 읽기전용 표시.
- **삭제**: 전체관리자만, 승인 전까지만. 관리번호 결번 처리.
