## 계산 규칙 (확정)

- **항목 금액**: 항상 공급가액(VAT 제외) 기준으로 입력.
- **항목 합계** = Σ(항목 금액 × 갯수).
- **공급가액 합계** = 항목 합계에 **십만단위 절사**(내림). 예: `12,345,678` → `12,300,000`.
- **부가세 금액** = 공급가액 합계(절사 후) × 0.1.
- **부가세 포함가** = 공급가액 합계 + 부가세 금액. (부가세 "포함" 선택 시 화면·문서에 함께 표기)
- 상세 구현: [`tech/08-calculation-rules.md`](../tech/08-calculation-rules.md).

## 유효성 (확정, [09-error-handling.md](./09-error-handling.md))

- 필수(Y) 필드 누락 시 저장 불가.
- 항목 금액/갯수에 음수 또는 0 입력 시 저장 불가.
- 반려 시 사유 미입력이면 반려 처리 불가.
