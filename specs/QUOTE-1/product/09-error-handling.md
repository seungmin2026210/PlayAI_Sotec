# 09. 예외 / 에러 처리

| 상황 | 처리 | HTTP |
|---|---|---|
| 삭제된 관리번호 | 재사용하지 않고 결번 처리 (그룹×연도 조합 내에서만 유효, [06-management-number.md](./06-management-number.md)) | — |
| 구매관리 데이터가 반영된 견적 수정/취소/삭제 시도 | 거부, "읽기전용" 표시 | 409 |
| 필수 항목 누락 | 저장 불가 ([05-data-fields.md](./05-data-fields.md) 필수 Y 필드 기준) | 422 |
| 항목 금액/갯수에 음수 또는 0 입력 | 저장 불가 | 422 |
| 반려 처리 시 사유 미입력 | 반려 처리 불가 | 422 |
| 허용되지 않는 상태 전이 | 거부 | 409 |
| 관리번호 999건 초과 (open-11) | 등록 차단 + 안내 메시지 | 409 |
| 그룹관리자가 쓰기 액션 시도 | 거부 | 403 |
| 그룹관리자가 타 그룹 견적 조회 시도 | 404 처리(존재 은닉) | 404 |
| 로그인 실패 (계정/PW 불일치) | 거부 | 401 |

## 에러 응답 포맷 (구현 결정)

```json
{ "detail": { "code": "PURCHASE_LOCKED", "message": "구매관리 데이터가 반영되어 수정할 수 없습니다." } }
```

- FastAPI 예외 핸들러에서 위 포맷으로 통일. 프론트는 `message`를 토스트로 표시.
- 세부 코드 목록: [`tech/04-api-endpoints.md`](../tech/04-api-endpoints.md).
