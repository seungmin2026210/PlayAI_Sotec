## 10.2 향후 로드맵 (범위 외)

- 예산 관리 기능
- 갱신 캘린더 기능
- 자산 배정 이력 자동 기록 기능
- 실제 로그인 인증 (출퇴근 프로그램 API 연동)
- 이메일 실제 발송 로직 (SMTP 등)
- 구매관리 시스템 실연동
- 그룹관리자 권한 확장 (등록/수정 등)
- 견적서 변경이력(감사로그) 기능
- 반려 재제출 건과 원본 견적서를 연결하는 참조 필드
