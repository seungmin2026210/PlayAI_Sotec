# ASSET-1 · 자산관리 (제품 스펙)

> 사용자 대면 동작 기준. 결정 근거는 [`DECISIONS.md`](./DECISIONS.md)(D1~D46), 구현은 [`TECH.md`](./TECH.md).
> 구매관리와 조율 사항: [`COORDINATION.md`](./COORDINATION.md) — 제안안대로 임시 확정해 구현됨(구매관리 담당자 확인 대기).

## 목적

회사가 **실제로 쓰고 있는** SW·HW·교육(강의 계정) 자산을 번호로 관리하고, **누가 무엇을 언제부터 언제까지
썼는지**를 남긴다. 구매관리에는 고객사 대리구매(재판매)품도 섞여 있으므로, 자산은 구매 기록 중 **골라서
가져오거나**, 구매 기록 없이 **직접 등록**한다.

## 범위

**포함**
- SW / HW / 교육 자산 등록(구매에서 가져오기 · 직접 등록, **수량 N건 한 번에**), 수정, 폐기, 삭제(잘못 등록한 기록, D47)
- 갱신(여러 자산 종료일 일괄 연장, 갱신 구매 연결)
- 실수 되돌리기: 배정 취소, 가져오기 취소
- 자산번호 자동 채번 `SW-26-001`
- 팀원 명단 관리(등록·수정·퇴사 처리)
- 사용자 배정(팀원 또는 **공용**) · 회수 · 사용자 변경(이관), 사용 이력(HISTORY)
- 사람별 보유 자산 조회
- 드롭다운 필터 + 키워드 검색, 엑셀 다운로드
- SW·교육 계정 비밀번호 암호화 저장, 전체관리자만 열람(열람 기록 저장)
- 메인 대시보드 갱신 캘린더 · 다가오는 갱신 일정 · 갱신 임박(D-30)/만료됨 KPI 실데이터 연동

**범위 밖(다음 단계)**
- 팀원 개인 로그인, 본인 자산 조회, 본인 비밀번호 열람
- 자산 신청→승인 흐름
- 대시보드 "갱신 임박 자산(예상 비용)" 표, "자산 현황" 표 실데이터화
- 계약관리 연동(지금은 계약번호 자유입력), 수료 관리, SW 버전 변경 이력, 감사로그 UI(비밀번호 열람 기록 조회 포함)
- 폐기 취소

## 사용자 · 권한

구매관리와 동일(새 역할 없음).

| 역할 | 자산 등록·수정·폐기·삭제·갱신·취소 | 배정·회수·이관·이력수정 | 팀원 명단 관리 | 비밀번호 보기 | 라이선스키 | 조회 |
|---|---|---|---|---|---|---|
| 전체관리자 | 가능 | 가능 | 가능 | 가능 | 전체 표시 | 전체 |
| 그룹관리자 | 불가(403) | 불가(403) | 불가(403, **본인 그룹 팀원만** 조회) | 불가(칸 자체 미노출) | 앞 4자리만(`XXXX-****`), 키 검색 불가 | **본인 그룹만** |

**자산의 그룹** = 팀원이 사용 중이면 **현재 사용자의 소속 그룹**, 미사용·공용이면 등록 시 지정한 그룹.
그룹관리자가 타 그룹 자산 상세에 직접 접근하면 `404`(존재 은닉, QUOTE-1과 동일). 삭제된 자산도 그룹관리자에겐 `404`.

## 자산 번호

`{유형}-{연도2자리}-{순번3자리}` — 예: `SW-26-001`, `HW-23-004`, `EDU-26-012`

- 유형(SW/HW/EDU)별·연도별로 따로 1부터 증가
- 연도 = **구매일의 연도**. 구매일을 모르면 등록한 해(한국 시간 기준)
- 여러 건을 한 번에 등록하면 연속 번호(`SW-26-001`~`SW-26-010`)
- 한 번 붙은 번호는 **절대 바뀌지 않음**(구매일을 나중에 고쳐도 그대로), 폐기돼도 재사용 안 함
- 한 해·한 유형에 999개 초과 시 등록 불가(`409 SEQ_EXHAUSTED`)

## 자산 1건의 단위

**자산 1건 = 사용자 1명(또는 공용 1곳).**
- Copilot Business 10석 → 자산 10건 (구매 기록 1건을 **수량 10**으로 가져오기)
- 마우스 5개 → 자산 5건 (직접 등록 **수량 5**)
- 인프런: **ID 1개 = 강의 1개 = 자산 1건**
- 라우터·회의실 모니터 등 → **공용** 배정(예: "3층 회의실")

### SW 전용
버전(현재 값만), 시리얼/라이선스키, 로그인 계정(ID), **비밀번호**

### HW 전용
제조사, 모델명, 제품 시리얼, MAC 주소(선택)

### 교육 전용
강의명, 강의 URL, 인프런 계정(ID), **비밀번호**

### 비밀번호
- DB엔 암호화 저장. 화면엔 `●●●●●●` + **[보기] [복사]** 버튼 — 전체관리자에게만 버튼 노출
- 그룹관리자 화면엔 비밀번호 칸 자체가 없음
- 목록, 키워드 검색, 엑셀 다운로드에는 포함되지 않음
- 수정 폼에서 비밀번호 칸을 **비워두면 기존 값 유지**. 지우려면 [비밀번호 삭제] 버튼
- [보기]/[복사]를 누를 때마다 누가·언제·어느 자산을 열람했는지 기록(조회 화면은 범위 밖)

### 배지(상태 아님)
- **만료**: 유효기간 종료일이 오늘(한국 시간)보다 이전
- **만료 임박**: 종료일까지 30일 이내
- 만료돼도 사용자를 자동으로 빼지 않는다(갱신 전까지 계속 쓰는 경우가 있음)

## 핵심 시나리오

1. **구매에서 가져오기**: [구매에서 가져오기] → 아직 가져오지 않은·갱신에 쓰이지 않은·폐기되지 않은 구매 유닛
   목록(해당 탭 유형만, 재판매품 포함 전부 보임)에서 골라 선택 → 구매일·금액·구매처·견적번호·상품명·키/계정·만료일이
   채워진 등록 폼 → **수량**(기본 1)·소분류 등 나머지 입력 후 저장 → 수량만큼 `SW-26-001`~ 연속 채번, 금액은 수량으로
   나눠 기록. 구매관리 목록엔 "자산 등록됨(SW-26-001 외 9건)" 표시. 같은 구매 유닛은 다시 가져올 수 없다.
   시리얼·계정 ID 등 자산마다 다른 값은 등록 후 각 자산에서 수정한다.
2. **직접 등록**: 구매 기록 없는 기존 장비 — [직접 등록] → 모든 항목 수동 입력, **수량**(기본 1)만큼 생성.
3. **배정**: 미사용 자산 상세 → [사용자 배정] → **팀원 명단에서 선택 또는 "공용"(장소/용도 입력)**, 사용 시작일(기본 오늘)
   → 상태 "사용 중". 교육 자산은 공용 배정 불가.
4. **사용자 변경(이관)**: 사용 중 자산 → [사용자 변경] → 새 사용자(팀원/공용), 변경일(기본 오늘) → 이전 사용자 이력은
   변경일로 종료, 새 사용자 이력이 변경일부터 시작. 한 번에 처리된다.
5. **회수**: [회수] → 사용 종료일(기본 오늘) → 상태 "미사용".
6. **교육 "제가 듣고 있어요"**: 교육 탭 목록에서 현재 수강자·수강 시작일이 바로 보인다. 누가 듣고 있는
   강의 계정은 다른 사람에게 배정할 수 없다(먼저 회수/이관).
7. **이력 확인·수정**: 자산 상세 하단 "사용 이력" — 사용자, 시작일, 종료일, 비고. 전체관리자는 날짜·비고를
   고칠 수 있다(사람은 못 바꿈). 수정한 사람·시각이 표시된다. 날짜는 아래 "날짜 규칙"을 따른다.
8. **배정 취소**: 사람을 잘못 골랐을 때 — 사용 중 자산 → [배정 취소] → 현재 배정 이력이 **삭제**되고 직전 상태로
   돌아간다(배정이었으면 미사용, 이관이었으면 이전 사용자가 다시 사용 중). 이미 회수된 이력은 취소할 수 없다.
9. **갱신**: 목록(또는 대시보드 갱신 일정 클릭)에서 같은 품명·같은 종료일 자산을 골라 [갱신] → 새 종료일(필수),
   새 시작일(기본: 이전 종료일 다음날), 갱신 구매 기록(선택) → 선택한 자산의 유효기간이 한꺼번에 연장된다.
   번호·사용자는 그대로. 연결한 구매 기록은 가져오기 목록에서 빠지고 구매관리에 "갱신에 사용됨" 표시.
   자산 상세에 갱신 기록이 쌓인다.
10. **사람별 조회**: [사용자별] 탭 — 팀원 목록(이름, 사번, 그룹, 재직, SW/HW/교육 사용 개수). 한 명을 누르면
    그 사람이 **지금 쓰는 자산 전체**와 **과거에 썼던 이력**. 그룹관리자는 본인 그룹 팀원만 보이고, 팀원의 과거
    자산이 지금 다른 그룹에서 쓰이고 있으면 이력 줄만 보이고 상세 링크는 없다("현재 다른 그룹 사용 중").
11. **팀원 명단 관리**: [사용자별] 탭에서 등록·수정·퇴사 처리. 퇴사자는 목록에서 흐리게 표시, 신규 배정 불가.
    사용 중 자산이 남아 있으면 퇴사 처리 시 경고(자동 회수는 안 함 — 임시 결정 P2). 이름을 고치면 지금 쓰는
    자산의 "현재 사용자" 이름도 바뀐다(과거 이력은 당시 이름 그대로).
12. **폐기**: 미사용 자산만 폐기 가능(사용 중이면 먼저 회수 — 임시 결정 P1). 폐기해도 번호·이력은 보존,
    기본 목록에서 숨김. 폐기 취소는 없다.
13. **가져오기 취소**: 구매에서 잘못 가져왔을 때 — 자산 상세 → [가져오기 취소] → 그 구매 기록에서 가져온 자산
    **N건 전체**가 폐기(사유 "가져오기 취소", 번호는 결번)되고 구매 기록은 다시 가져올 수 있게 된다. N건 중 하나라도
    사용 이력이 있으면 거부(먼저 배정 취소).
14. **삭제**(D47): 잘못 등록한 기록을 없앨 때 — 자산 상세 → [삭제] → **사유 입력(필수)** → 상태 "삭제됨".
    미사용이고 배정 이력·갱신 기록이 없는 **직접 등록** 자산만 가능(가져온 자산은 [가져오기 취소], 이력이 있으면 [폐기]).
    조건이 안 맞으면 버튼이 비활성화되고 이유를 툴팁으로 보여준다. 되돌릴 수 없고 번호는 결번.
    기본 목록·검색·엑셀·대시보드에서 사라지며, 상태 필터 "삭제됨"(전체관리자만)에서 삭제자·시각·사유를 볼 수 있다.
15. **엑셀 다운로드**: 현재 탭·필터가 적용된 목록 그대로(비밀번호 제외, 그룹관리자는 라이선스키 앞 4자리만).

### 날짜 규칙 (배정 · 회수 · 이관 · 이력 수정 공통)

- **미래 날짜 불가** — 오늘(한국 시간)까지만. "사용 중"은 지금 실제로 쓰고 있다는 뜻
- 종료일은 시작일보다 앞설 수 없음
- 같은 자산의 다른 이력과 기간이 겹칠 수 없음(예: 앞 사용자 종료일 이전 날짜로 새 배정 불가)
- 이관 변경일은 현재 사용 시작일과 같거나 이후
- 사용 중인 이력의 종료일은 이력 수정으로 채울 수 없음 — [회수]나 [사용자 변경]으로

**목록 컬럼(예시)**: 자산번호 · 소분류 · 품명 · 현재 사용자 · 사용 시작일 · 유효기간 종료일(+배지) · 그룹 · 상태
(SW는 버전, HW는 모델명, 교육은 강의명을 추가)

**드롭다운 필터**: 소분류 · 사용자("공용" 포함) · 그룹 · 상태(미사용/사용 중/폐기/삭제됨 — 삭제됨은 전체관리자만) · 만료 여부(만료/30일 내/정상) · 구매 연도

**키워드 검색 대상**: 자산번호, 품명, 시리얼/라이선스키, 계정 ID, 제조사/모델명, 강의명, 견적번호, 계약번호, 비고
(비밀번호는 검색 대상 아님. 라이선스키 검색은 전체관리자만)

기본: 폐기·삭제 숨김, 자산번호 역순.

## 메인 대시보드 연동

| 위젯 | 이번 범위 | 데이터 |
|---|---|---|
| 갱신 임박 (D-30) KPI | **실데이터** | 30일 내 유효기간 종료 자산 수 / 90일 내 건수 / **만료됨(미처리) 건수**(종료일 지났는데 갱신·폐기 안 한 자산, 클릭 시 만료 필터 목록) |
| 갱신 캘린더 | **실데이터** | 월별, 종료일에 표시 |
| 다가오는 갱신 일정 | **실데이터** | 가까운 순 |
| 갱신 임박 자산 표(예상 비용) | 목업 유지 | 예상 비용 필드 없음 |
| 자산 현황 표 | 목업 유지 | |

- 대상: 유효기간 종료일이 있는 자산(SW·교육, HW는 입력한 경우만), 폐기·삭제 제외
- **같은 날·같은 품명은 한 줄로 묶음** — 예: "9/1 GitHub Copilot Business 10건 갱신"
- 클릭 → 자산관리 해당 탭, 해당 품명·종료일로 필터된 목록(여기서 바로 [갱신] 가능)
- 그룹관리자는 자기 그룹 자산만

## 예외 처리

| 상황 | 응답 |
|---|---|
| 이미 가져온(또는 갱신에 쓴) 구매 유닛을 다시 가져오기·갱신에 연결 | `409 ALREADY_IMPORTED` |
| 폐기된 구매 유닛 가져오기 | `409 ALREADY_RETIRED` |
| 사용 중인 자산에 배정 | `409 ASSET_NOT_IDLE` |
| 사용 중인 자산 폐기 | `409 ASSET_IN_USE` |
| 폐기된 자산 수정·배정·갱신·삭제 | `409 ASSET_DISPOSED` |
| 삭제된 자산 수정·배정·갱신·폐기·삭제 | `409 ASSET_DELETED` |
| 구매에서 가져온 자산 삭제 | `409 ASSET_IMPORTED` |
| 배정 이력·갱신 기록이 있는(또는 사용 중인) 자산 삭제 | `409 ASSET_HAS_HISTORY` |
| 퇴사자에게 배정·이관 | `409 MEMBER_INACTIVE` |
| 사용 이력이 있는 자산이 섞인 가져오기 취소 | `409 ASSET_HAS_HISTORY` |
| 사용 중이 아닌 자산의 배정 취소 | `409 ASSET_NOT_IN_USE` |
| 날짜 규칙 위반(미래 날짜, 종료일 < 시작일, 기간 겹침, 이관일 < 사용 시작일), 교육 자산 공용 배정, 유형 변경 시도, 수량 범위 밖(1~100), 새 종료일 ≤ 기존 종료일·종료일 없는 자산·종료일이 서로 다른 자산을 섞어서 갱신 | `400 VALIDATION_ERROR` |
| 연·유형 순번 999 초과(수량 N건 중 하나라도) | `409 SEQ_EXHAUSTED`(한 건도 생성 안 됨) |
| 비밀번호 암호화 키 미설정 | `501 SECRET_KEY_MISSING` — 비밀번호가 **포함된** 등록·수정·열람 요청은 통째로 실패, 비밀번호 없는 요청은 정상 |
| 그룹관리자의 쓰기 시도 | `403 FORBIDDEN_ROLE` |
| 그룹관리자가 타 그룹 자산 상세 | `404 NOT_FOUND` |
