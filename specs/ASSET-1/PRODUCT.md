# ASSET-1 · 자산관리 (제품 스펙)

> 사용자 대면 동작 기준. 결정 근거는 [`DECISIONS.md`](./DECISIONS.md)(D1~D30), 구현은 [`TECH.md`](./TECH.md).
> 구매관리와 조율 필요 사항: [`COORDINATION.md`](./COORDINATION.md) — **합의 전 구현 착수 금지.**

## 목적

회사가 **실제로 쓰고 있는** SW·HW·교육(강의 계정) 자산을 번호로 관리하고, **누가 무엇을 언제부터 언제까지
썼는지**를 남긴다. 구매관리에는 고객사 대리구매(재판매)품도 섞여 있으므로, 자산은 구매 기록 중 **골라서
가져오거나**, 구매 기록 없이 **직접 등록**한다.

## 범위

**포함**
- SW / HW / 교육 자산 등록(구매에서 가져오기 · 직접 등록), 수정, 폐기
- 자산번호 자동 채번 `SW-26-001`
- 팀원 명단 관리(등록·수정·퇴사 처리)
- 사용자 배정 · 회수 · 사용자 변경(이관), 사용 이력(HISTORY)
- 사람별 보유 자산 조회
- 드롭다운 필터 + 키워드 검색, 엑셀 다운로드
- SW·교육 계정 비밀번호 암호화 저장, 전체관리자만 열람
- 메인 대시보드 갱신 캘린더 · 다가오는 갱신 일정 · 갱신 임박(D-30) KPI 실데이터 연동

**범위 밖(다음 단계)**
- 팀원 개인 로그인, 본인 자산 조회, 본인 비밀번호 열람
- 자산 신청→승인 흐름
- 대시보드 "갱신 임박 자산(예상 비용)" 표, "자산 현황" 표 실데이터화
- 계약관리 연동(지금은 계약번호 자유입력), 수료 관리, SW 버전 변경 이력, 감사로그 UI

## 메뉴 구조

```
계약관리
 ├ 견적관리   /quotes
 ├ 구매관리   /purchase
 ├ 계약관리   /contract
 └ 자산관리   /assets        ← 신규
      화면 상단 탭: [SW] [HW] [교육] [사용자별]
```

## 사용자 · 권한

구매관리와 동일(새 역할 없음).

| 역할 | 자산 등록·수정·폐기 | 배정·회수·이관·이력수정 | 팀원 명단 관리 | 비밀번호 보기 | 조회 |
|---|---|---|---|---|---|
| 전체관리자 | 가능 | 가능 | 가능 | 가능 | 전체 |
| 그룹관리자 | 불가(403) | 불가(403) | 불가(403, 조회만) | 불가(칸 자체 미노출) | **본인 그룹만** |

**자산의 그룹** = 사용 중이면 **현재 사용자의 소속 그룹**, 미사용이면 등록 시 지정한 그룹.
그룹관리자가 타 그룹 자산 상세에 직접 접근하면 `404`(존재 은닉, QUOTE-1과 동일).

## 자산 번호

`{유형}-{연도2자리}-{순번3자리}` — 예: `SW-26-001`, `HW-23-004`, `EDU-26-012`

- 유형(SW/HW/EDU)별·연도별로 따로 1부터 증가
- 연도 = **구매일의 연도**. 구매일을 모르면 등록한 해
- 한 번 붙은 번호는 **절대 바뀌지 않음**(구매일을 나중에 고쳐도 그대로), 폐기돼도 재사용 안 함
- 한 해·한 유형에 999개 초과 시 등록 불가(`409 SEQ_EXHAUSTED`)

## 자산 1건의 단위

**자산 1건 = 사용자 1명.**
- Copilot Business 10석 → 자산 10건
- 마우스 5개 → 자산 5건
- 인프런: **ID 1개 = 강의 1개 = 자산 1건**

## 데이터 항목

### 공통

| 항목 | 입력 | 비고 |
|---|---|---|
| 자산번호 | 자동 | 수정 불가 |
| 소분류 | 드롭다운 | SW: 라이선스 / AI 구독 / 기타 · HW: 노트북 / 모니터 / 마우스 / 키보드 / 허브 / 라우터 / 기타 · 교육: 없음 (초기 목록은 임시, DECISIONS P7) |
| 품명 | 필수 | 예: "GitHub Copilot Business", "LG gram 16" |
| 그룹 | 필수 | 미사용일 때의 소속 그룹 |
| 구매일 | 선택 | 번호 연도의 기준 |
| 금액 / 구매처 | 선택 | 원 단위 정수 |
| 견적번호 | 자동(가져오기) / 선택 | 견적 상세로 링크 |
| 계약번호 | 자유 입력 | **임시** — 계약관리 생기면 링크로 교체 |
| 연결 구매 | 자동(가져오기) | 구매 유닛번호(예: `인텔리제이-001`), 구매 상세로 링크 |
| 유효기간 시작 / 종료 | 선택 | 라이선스·구독 기간. 종료일 = 갱신일, 대시보드 캘린더에 표시 |
| 비고 | 선택 | |
| 상태 | 자동 | 미사용 / 사용 중 / 폐기 — 직접 못 바꿈(배정·회수·폐기 동작으로만) |
| 현재 사용자 | 자동 | 배정 동작으로만 변경 |

### SW 전용
버전(현재 값만), 시리얼/라이선스키, 로그인 계정(ID), **비밀번호**

### HW 전용
제조사, 모델명, 제품 시리얼, MAC 주소(선택)

### 교육 전용
강의명, 강의 URL, 인프런 계정(ID), **비밀번호**

### 비밀번호
- DB엔 암호화 저장. 화면엔 `●●●●●●` + **[보기] [복사]** 버튼 — 전체관리자에게만 버튼 노출
- 그룹관리자 화면엔 비밀번호 칸 자체가 없음
- 목록, 키워드 검색, 엑셀 다운로드에는 포함되지 않음

### 배지(상태 아님)
- **만료**: 유효기간 종료일이 오늘보다 이전
- **만료 임박**: 종료일까지 30일 이내
- 만료돼도 사용자를 자동으로 빼지 않는다(갱신 전까지 계속 쓰는 경우가 있음)

## 핵심 시나리오

1. **구매에서 가져오기**: [구매에서 가져오기] → 아직 가져오지 않은·폐기되지 않은 구매 유닛 목록(해당 탭 유형만,
   재판매품 포함 전부 보임)에서 골라 선택 → 구매일·금액·구매처·견적번호·상품명·키/계정·만료일이 채워진 등록
   폼 → 소분류 등 나머지 입력 후 저장 → `SW-26-001` 채번. 구매관리 목록엔 "자산 등록됨(SW-26-001)" 표시.
   같은 구매 유닛은 다시 가져올 수 없다.
2. **직접 등록**: 구매 기록 없는 기존 장비 — [직접 등록] → 모든 항목 수동 입력.
3. **배정**: 미사용 자산 상세 → [사용자 배정] → 팀원 명단에서 선택, 사용 시작일(기본 오늘) → 상태 "사용 중".
4. **사용자 변경(이관)**: 사용 중 자산 → [사용자 변경] → 새 사용자, 변경일(기본 오늘) → 이전 사용자 이력은
   변경일로 종료, 새 사용자 이력이 변경일부터 시작. 한 번에 처리된다.
5. **회수**: [회수] → 사용 종료일(기본 오늘) → 상태 "미사용".
6. **교육 "제가 듣고 있어요"**: 교육 탭 목록에서 현재 수강자·수강 시작일이 바로 보인다. 누가 듣고 있는
   강의 계정은 다른 사람에게 배정할 수 없다(먼저 회수/이관).
7. **이력 확인·수정**: 자산 상세 하단 "사용 이력" — 사용자, 시작일, 종료일, 비고. 전체관리자는 날짜·비고를
   고칠 수 있다(사람은 못 바꿈). 수정한 사람·시각이 표시된다.
8. **사람별 조회**: [사용자별] 탭 — 팀원 목록(이름, 사번, 그룹, 재직, SW/HW/교육 사용 개수). 한 명을 누르면
   그 사람이 **지금 쓰는 자산 전체**와 **과거에 썼던 이력**.
9. **팀원 명단 관리**: [사용자별] 탭에서 등록·수정·퇴사 처리. 퇴사자는 목록에서 흐리게 표시, 신규 배정 불가.
   사용 중 자산이 남아 있으면 퇴사 처리 시 경고(자동 회수는 안 함 — 임시 결정 P2).
10. **폐기**: 미사용 자산만 폐기 가능(사용 중이면 먼저 회수 — 임시 결정 P1). 폐기해도 번호·이력은 보존,
    기본 목록에서 숨김.
11. **엑셀 다운로드**: 현재 탭·필터가 적용된 목록 그대로(비밀번호 제외).

## 목록 · 검색 (SW/HW/교육 탭 공통)

**목록 컬럼(예시)**: 자산번호 · 소분류 · 품명 · 현재 사용자 · 사용 시작일 · 유효기간 종료일(+배지) · 그룹 · 상태
(SW는 버전, HW는 모델명, 교육은 강의명을 추가)

**드롭다운 필터**: 소분류 · 사용자 · 그룹 · 상태(미사용/사용 중/폐기) · 만료 여부(만료/30일 내/정상) · 구매 연도

**키워드 검색 대상**: 자산번호, 품명, 시리얼/라이선스키, 계정 ID, 제조사/모델명, 강의명, 견적번호, 계약번호, 비고
(비밀번호는 검색 대상 아님)

기본: 폐기 숨김, 자산번호 역순.

## 메인 대시보드 연동

| 위젯 | 이번 범위 | 데이터 |
|---|---|---|
| 갱신 임박 (D-30) KPI | **실데이터** | 30일 내 유효기간 종료 자산 수 / 90일 내 건수 |
| 갱신 캘린더 | **실데이터** | 월별, 종료일에 표시 |
| 다가오는 갱신 일정 | **실데이터** | 가까운 순 |
| 갱신 임박 자산 표(예상 비용) | 목업 유지 | 예상 비용 필드 없음 |
| 자산 현황 표 | 목업 유지 | |

- 대상: 유효기간 종료일이 있는 자산(SW·교육, HW는 입력한 경우만), 폐기 제외
- **같은 날·같은 품명은 한 줄로 묶음** — 예: "9/1 GitHub Copilot Business 10건 갱신"
- 클릭 → 자산관리 해당 탭, 해당 품명·종료일로 필터된 목록
- 그룹관리자는 자기 그룹 자산만

## 예외 처리

| 상황 | 응답 |
|---|---|
| 이미 가져온 구매 유닛을 다시 가져오기 | `409 ALREADY_IMPORTED` |
| 폐기된 구매 유닛 가져오기 | `409 ALREADY_RETIRED` |
| 사용 중인 자산에 배정 | `409 ASSET_NOT_IDLE` |
| 사용 중인 자산 폐기 | `409 ASSET_IN_USE` |
| 폐기된 자산 수정·배정 | `409 ASSET_DISPOSED` |
| 퇴사자에게 배정 | `409 MEMBER_INACTIVE` |
| 종료일 < 시작일, 이력 기간 겹침 | `400 VALIDATION_ERROR` |
| 연·유형 순번 999 초과 | `409 SEQ_EXHAUSTED` |
| 비밀번호 암호화 키 미설정 | `501 SECRET_KEY_MISSING`(비밀번호 저장/열람만 실패, 나머지 동작) |
| 그룹관리자의 쓰기 시도 | `403 FORBIDDEN_ROLE` |
| 그룹관리자가 타 그룹 자산 상세 | `404 NOT_FOUND` |
